Getting Started

Deploy your server, scan the QR code, start coding. The whole process takes about 5 minutes.

What you need

  • ✓ Continuum installed on your iPhone or iPad
  • ✓ A Mac or Linux machine to run the installer (your laptop is fine)
  • ✓ gum — the interactive UI used by deploy.sh (brew install gum)
  • ✓ For cloud deploys: the provider's CLI (aws, doctl, or hcloud) authenticated to your account

The installer itself only needs bash and curl, which both macOS and Linux already have.

Install the server

One command. The installer downloads deploy.sh from the latest signed release, verifies its checksum, then runs it. deploy.sh walks you through provider, region, and instance size interactively (powered by gum).

🚀 One-line install

Run this on your laptop. It works for new cloud VMs (Lightsail / EC2 / DigitalOcean / Hetzner), an existing Linux VPS you can SSH into, or your local Mac/Linux machine. The installer asks which path to take.

/bin/bash -c "$(curl -fsSL https://kalleeh.github.io/continuum/install.sh)"
  1. The installer fetches the latest deploy.sh + cloud-init.yaml from github.com/kalleeh/continuum-relay/releases/latest and verifies their sha256.
  2. deploy.sh asks you to pick a target (cloud provider, existing VPS, or local), then provisions everything. Wait ~3 minutes.
  3. A QR code appears in your terminal containing the WireGuard config + auth token for the first device.
  4. Open Continuum on your iPhone → tap Set Up My Server → point the camera at the terminal. Done.

Want to inspect before running? Read install.sh (≈100 lines) or download deploy.sh directly from the release.

After scanning the QR code

The app imports your WireGuard config and auth token automatically. The VPN connects, and you'll see the session list within a few seconds.

From there:

  • + Tap New Session to create a Claude Code, Kiro, Ollama, or terminal session
  • + Sessions run on your server inside tmux — they keep running even when you close the app
  • + Come back anytime and pick up exactly where you left off

Troubleshooting

The QR code won't scan
Make sure your terminal window is large enough for the QR code to render clearly. Try zooming in or increasing your terminal font size. You can also re-display the QR code with ./deploy.sh status.
VPN connects but no sessions appear
The relay service may still be starting. Wait 30 seconds and pull down to refresh. Check that the relay is running on your server: systemctl status continuum-relay.
"Connection failed" after scanning
Your phone needs to be on a network that can reach your server. If you're on the same local network as a local install, make sure your firewall allows UDP port 51820 (WireGuard).
I want to add another device
SSH into the server and run continuum-relay peers add name. The command prints a QR JSON payload — render it with qrencode -t ANSIUTF8 in another terminal and scan with the iOS app. No re-deploy needed.
How do I update the server?
Re-run the one-line installer. It pulls the latest signed release, verifies the checksum, and re-runs deploy.sh — which is idempotent and only restarts services if the binary actually changed.
